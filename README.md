# UPI-Fraud-Statistical-Analysis
Statistical analysis of financial transactions to identify unusual fraud patterns.
UPI Fraud Statistical Analysis

Project Overview

This project analyzes digital financial transactions using statistical methods to identify unusual patterns that may indicate fraud.

Objectives

- Understand transaction data.
- Analyze transaction amounts and transaction types.
- Identify unusual transactions using statistical methods.
- Explore possible fraud indicators.

Statistical Methods Used

- Descriptive Statistics
- Outlier Detection using IQR
- Z-Score Analysis
- Hypothesis Testing
- Correlation Analysis

Tools Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

Project Notebook

The complete analysis and visualizations are available in the Jupyter Notebook uploaded in this repository.

Conclusion

This project uses statistical analysis to explore unusual transaction patterns and possible indicators of financial fraud. Outliers should be investigated further and should not automatically be classified as fraud.

Limitation

The dataset used in this project is synthetic and may not represent every real-world UPI transaction pattern.
